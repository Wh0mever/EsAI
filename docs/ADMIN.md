# Админ-панель EsAI

Доступ: `https://<домен>/admin/` (учётка суперпользователя).

Создать суперпользователя:
```bash
docker compose -f compose.yaml -f compose.https.yaml exec core \
  python manage.py createsuperuser
```

## Дашборд аналитики
`https://<домен>/admin/audit-dashboard/` (ссылка есть на главной админки).
Показывает: пользователи (всего/сегодня/30д), сообщения и запросы, активные
пользователи, оплаты и выручку, средний чек, списанные/начисленные токены,
популярные модели и запросы по моделям, счётчики ошибок.
> Расход OpenRouter и прибыль — **оценочные** (ставка `AUDIT_OPENROUTER_USD_PER_TOKEN`
> в .env), т.к. точная цена за токен по моделям в БД не хранится. Выручка может
> смешивать валюты — помечено.

## Управление моделями (раздел «GPT модели»)
Без кода: добавить/выключить модель, задать:
- **Отображаемое имя** (напр. «ChatGPT») и **OpenRouter ID** (`openai/gpt-4o`)
- **Коэффициент наценки** (`markup_coefficient`) — во сколько раз списывать токены
- **System Prompt / Temperature / Top P / Max Tokens** — параметры генерации
- **Сортировку** и **активность** (видимость в селекторе чата)
Список моделей в чате формируется из активных записей (эндпоинт `/api/ai/models/`).

## Токены и оплаты
- **Пакеты токенов** (`TokenPackage`): имя, кол-во токенов, бонус, цена (KGS), активность.
- **Транзакции токенов** (`TokenTransaction`): леджер списаний/начислений (только просмотр).
- **Платежи** (`Payment`): история операций FreedomPay.
- **Пользователи**: поле **Баланс токенов** редактируется вручную; блокировка через `is_active`.

## Криптооплата (панель /admin-new, раздел «Настройки»)
Карточка «Криптооплата (NOWPayments)»:
- **Режим**: `Выключено` (метода нет ни у кого) / `Только сотрудникам`
  (для проверки боевых ключей, обычные люди платят как раньше) / `Включено`.
- **API-ключ** и **IPN-секрет** — вводятся здесь и наружу отдаются только
  маской. Пустое поле при сохранении = «убрать значение», начнёт действовать
  ключ из `.env`. Без IPN-секрета вебхуки не принимаются вообще.
- **Курс сом → доллар** — в отличие от рублёвого он ПЛАТЁЖНЫЙ: по нему
  выставляется счёт. Пусто = брать живой курс (обновляется раз в час);
  рядом показан рыночный, чтобы видеть расхождение.
- **Комиссию процессора платит покупатель** — включено: комиссия NOWPayments
  (0.5%) и сети добавляется к сумме перевода, продавец получает полную цену
  пакета; выключено: комиссия вычитается из выручки. Курс счёта плавающий
  (`NOWPAYMENTS_FIXED_RATE=0`): с фиксацией процессор поднимает минимальную
  сумму почти вдвое, а сумма в монете и так называется один раз при создании.
- **Монеты** — флажками, без правки кода. На витрине под каждой монетой
  показан минимум процессора («от $11.36»); монеты, которыми пакет оплатить
  нельзя (минимум выше цены), погашены с объяснением. Сам минимум задаёт
  кабинет NOWPayments: он складывается из комиссии вывода на кошелёк продавца
  (USDT TRC-20 — около $5, USDT на BEP-20/TON — центы) и автоконвертации,
  если она включена. Дешёвые пакеты станут оплачиваемыми, когда в кабинете
  выбран кошелёк выплат в дешёвой сети и выключена конвертация.
- **Проверить подключение** — дёргает процессор и показывает, сколько монет
  включено в его кабинете и задан ли IPN-секрет.

В разделе «Платежи» появились фильтры (крипта / карты / без оплаты /
нужен разбор), третье состояние **⏳ Ждём перевод** (криптосчёт живёт до часа,
и «неуспешно» для него было бы неправдой) и кнопка **Перепроверить**: она
спрашивает процессор заново и проводит платёж тем же путём, что и обычно, —
руками кредиты начислять не нужно.

## Настройки сайта (`SiteSettings`, синглтон)
Лого, favicon, название, контакты (email/телефон), соцссылки, тексты футера/
поддержки/ошибок. Отдаётся фронту через `/api/content/site-settings/`.

## SEO из админки
- **PageSeo**: по пути страницы (напр. `/`, `/model/chatgpt`) — Title, Description,
  Keywords, OG, Canonical, Robots. Отдаётся `/api/content/page-seo/?path=...`.
- **Статьи блога** (`BlogPost`): создание/редактирование/публикация (slug, meta,
  обложка, контент, is_published). Отдаются `/api/content/articles/`.

## Логи (`EventLog`, раздел audit)
Только просмотр: входы, оплаты, ошибки сервера/OpenRouter/FreedomPay (фильтры по
типу/уровню/дате).

## Промпт-шаблоны, провайдеры
`AiPromptTemplate` — пользовательские/публичные шаблоны промптов. `AiProvider` —
справочник (ключ OpenRouter берётся из `.env`, не из БД).

### Валюта кошелька выплат (`crypto_settlement_currency`)

Минимальная сумма счёта у NOWPayments зависит от пары «чем платят → куда
выплачивается продавцу». Справочник «→ доллар» показывал $12 для монет, которыми
$2 принимались, и витрина их гасила. В поле вводится код валюты кошелька выплат из
кабинета процессора (например `usdtbsc`) — с ним минимумы совпадают с реальностью
(проверено 6 сентября 2026: 12 из 12). Поменяли кошелёк выплат — поменяйте и поле.
USDT TRC-20 при любой настройке остаётся от ~$11: это порог процессора для сети TRON.
