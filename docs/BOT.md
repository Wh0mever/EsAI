# Telegram-бот EsAI

## Что сделано и где оно живёт

| Слой | Где | Что делает |
|---|---|---|
| Бэкенд | `core/botapi/` | Обмен «данные Telegram → токен человека», оплата Stars, привязка аккаунтов, уведомления из ядра |
| Голос | `core/ai/stt.py`, `POST /api/ai/transcribe/` | Голосовое → текст через модель, цена по минутам |
| Очередь видео | `core/ai/generation.py`, `GenerationJob`, `POST /api/ai/jobs/` | Ролики генерируются в воркере `celery_media`, результат приходит в бот сообщением |
| Бот | `bot/` | Отдельный сервис на aiogram: чат, модели, файлы, голос, картинки, видео, студия, оплата, профиль |
| Mini App | `next/src/app/tg/`, `nginx /tg/` | Полная студия внутри Telegram с автологином по `initData` |

Бот — тонкий клиент нашего же API. Он не считает деньги, не ходит в базу и не
знает ключей моделей: списания, лимиты, антифрод и история остаются на сайте,
по тем же адресам, что использует веб-фронт. Поэтому деньги считаются в одном
месте, а не в двух, и бот нельзя «обмануть» в обход сайта.

## Аккаунт общий с сайтом

Вход через Telegram на сайте заводит `SocialAccount(provider="telegram",
uid=<id пользователя>)` и пользователя с почтой-заглушкой
`telegram_<id>@social.esai.local`. Бот ищет и создаёт ровно то же самое —
а id пользователя в Telegram один на все боты. Поэтому человек, который
пополнил баланс на сайте, видит эти кредиты в боте, и наоборот.

Если на сайте человек входит по почте, аккаунты можно связать двумя путями:

- **из бота**: Профиль → «Связать с аккаунтом сайта» → почта → код с почты.
  Заглушка из бота вливается в аккаунт сайта: чаты, мультфильмы, память и
  купленные кредиты переезжают, подарочные (приветственный и ежедневный
  бонус) — нет, чтобы бонус не выдавался дважды;
- **с сайта**: `POST /api/users/telegram/link/start/` отдаёт ссылку
  `t.me/<бот>?start=link_<код>` на 10 минут (кнопку в профиль сайта можно
  повесить на этот эндпоинт).

Если у заглушки были платежи, автоматически не сливаем (409
`telegram_bound_to_paid_account`) — это ручной разбор.

Товарный бот и бот входа на сайт — **разные боты с разными токенами**
(`TELEGRAM_PRODUCT_BOT_TOKEN` и `TELEGRAM_BOT_TOKEN`). На общий аккаунт это
не влияет.

## Включение

```bash
cd /opt/esai && bash scripts/bot-up.sh
```

Скрипт спросит токен от @BotFather (ввод скрыт), проверит его у Telegram
**до** записи в `.env`, сам сгенерирует служебный секрет, поднимет сервисы
(`core`, `celery_media`, `bot`), проставит пакетам цены в Stars по курсу и
покажет самопроверку. Ваш Telegram id можно узнать у @userinfobot.

Бот стартует в режиме `staff` — отвечает только тем, чьи id перечислены в
`BOT_STAFF_IDS`. После обкатки:

```bash
bash scripts/bot-open.sh    # отвечает всем
```

Проверить окружение в любой момент:

```bash
docker compose exec bot python -m bot.selfcheck
docker compose logs -f bot
docker compose logs -f celery_media
```

В @BotFather стоит сделать `/setjoingroups` → Disable и `/setprivacy` →
Enable: бот работает только в личке.

## Что умеет бот

- `/start` — приветствие, выбор языка (ru/en/kg), восемь стартовых подсказок;
  ссылки `?start=ref_КОД`, `?start=promo_КОД`, `?start=link_КОД`,
  `?start=studio`, `?start=topup`.
- Чат с любой моделью: ответ показывается по мере появления, под ним —
  «повторить», «продолжить», источники и ход рассуждений.
- `/model` — те же группы и пометки, что на сайте, с ценой и «🔒 Премиум».
- Файлы: PDF, Word, Excel, PowerPoint, TXT и фото; готовые действия.
- **Голосовые и кружки**: распознаются на сервере (`STT_CREDITS_PER_MINUTE`
  кредитов за минуту, по умолчанию 2), текст показывается человеку и уходит
  в чат как обычный вопрос.
- `/image` — мастер картинок: модель, пропорции, кнопки «ещё вариант»,
  «другие пропорции», «изменить», «оригинал». Фото → «Отредактировать».
- `/video` — мастер видео: модель, промпт или фото как первый кадр,
  длительность/пропорции/разрешение с живой ценой. Ролик генерируется в
  очереди на сервере; бот показывает прогресс, а готовый файл присылает ядро —
  даже если бот тем временем перезапускался. Кнопки «продлить», «ещё вариант»,
  «поделиться» (публичная ссылка `/v/<код>`).
- `/studio` — мастер мультфильмов: аудитория → герой (библиотека, своё фото,
  нарисовать) → разделы → сцены с превью → лента → снять/переснять/переставить
  → собрать; «Мои мультфильмы»; кнопка «Открыть полную студию» (Mini App).
  О готовности сцен и мультфильма ядро сообщает пушем.
- `/balance` с историей операций; `/topup` — оплата Telegram Stars (см. ниже).
- `/profile`, `/lang`, `/notify` (тумблеры уведомлений), `/memory`,
  `/referral` (ссылка ведёт в бота), `/transfer`, `/promo`, `/support`,
  `/feedback`, `/faq`, блог, `/delete`, «☰ Ещё».
- Уведомления от сайта в бот: пополнение, реферальные начисления, ежедневный
  бонус, готовность сцен и мультфильмов, готовое видео.

## Оплата Telegram Stars

По правилам Telegram цифровые товары в ботах и Mini App продаются только за
Stars; ссылок на карту и крипту из бота нет (текстом упоминается сайт, где
у человека тот же аккаунт).

- Цена пакета в Stars — поле `stars_price` пакета в админке (пусто — в боте
  не продаётся), бонус за оплату в боте — `stars_bonus_tokens`. Рядом
  показывается подсказка по формуле «выручка как с сомов»
  (`plans/stars.py`, 1 Star = $0.013 для владельца). Первая раскладка:
  `manage.py set_stars_prices --apply`.
- Режим: `stars_payments_mode` в настройках админки (`off` / `staff` / `on`),
  по умолчанию `STARS_PAYMENTS_MODE=on`.
- Путь: `/topup` → согласие с условиями (`/terms`) → `sendInvoice` →
  `pre_checkout_query` проверяется на сервере (`/api/bot/stars/precheck/`) →
  `successful_payment` → `/api/bot/stars/confirm/` → кредиты, тир paid,
  реферальная доля. Идемпотентно по `telegram_payment_charge_id`.
- Расхождение суммы/валюты/покупателя или второй платёж по оплаченному счёту —
  **автовозврат** Stars и запись в `StarInvoice.flags`.
- Если сервер был недоступен в момент оплаты, бот кладёт подтверждение в
  очередь в Redis и повторяет раз в минуту; параллельно раз в 10 минут ядро
  сверяет журнал `getStarTransactions` и дозачисляет пропущенное.
- Возврат: админка → платёж → «Вернуть Stars» (`POST
  /api/manage/payments/<id>/refund-stars/`), только полный; кредиты изымаются
  тем же клобэком, что при возврате карточной оплаты. Если кредиты уже
  потрачены — без `force` возврат не делается. Апдейт `refunded_payment`
  (возврат со стороны Telegram) обрабатывается так же.
- Stars лежат на балансе бота и выводятся его владельцем в @BotFather через
  Fragment (доступны до 21 дня после оплаты).

## Переменные окружения

| Переменная | Значение |
|---|---|
| `TELEGRAM_PRODUCT_BOT_TOKEN`, `TELEGRAM_PRODUCT_BOT_USERNAME` | Товарный бот |
| `BOT_SERVICE_SECRET` | Подпись служебных запросов бота (генерирует скрипт) |
| `BOT_ACCESS` (`staff`/`all`), `BOT_STAFF_IDS` | Кому отвечает бот |
| `TELEGRAM_NOTIFY_ENABLED` | Уведомления из ядра в Telegram |
| `BOT_MODE` (`polling`/`webhook`), `BOT_WEBHOOK_BASE`, `BOT_WEBHOOK_SECRET`, `BOT_WEBHOOK_PATH`, `BOT_WEBHOOK_PORT` | Вебхук: nginx уже проксирует `/tg-webhook/` на `bot:8081` только с сетей Telegram |
| `STT_MODEL`, `STT_CREDITS_PER_MINUTE`, `STT_MAX_SECONDS`, `STT_MAX_BYTES` | Распознавание голоса |
| `CELERY_MEDIA_QUEUE`, `CELERY_MEDIA_CONCURRENCY` | Очередь долгих генераций (видео, сцены студии) |
| `STARS_PAYMENTS_MODE` | Оплата Stars по умолчанию |

## Ограничения, которые важно помнить

- Опрос Telegram ведёт **ровно один процесс** (блокировка в Redis).
- Сообщение — до 4096 символов, правка не чаще раза в секунду на чат.
- Скачать файл бот может до 20 МБ (Telegram), наш API принимает до 15 МБ,
  голосовое — до 5 МБ и 120 секунд, видео по URL — до 20 МБ (иначе ссылка).
- `TELEGRAM_NOTIFY_ENABLED=0` полностью выключает исходящие сообщения.
- Пустой `BOT_SERVICE_SECRET` закрывает служебные эндпоинты.
- Сцены студии и видео из бота идут в воркер `celery_media`; если он не
  запущен, они висят в очереди (`docker compose up -d celery_media`).

## Тесты

```bash
# бэкенд (на стенде, не на проде)
cd core && TEST_DB=test_bot python manage.py test botapi payments.tests_stars ai.tests_stt ai.tests_jobs --settings=core.settings_localtest

# бот
cd bot && python -m pytest tests -q
```

Ни один тест не ходит в сеть: Telegram и наш API подменяются заглушками.

## Что проверить после включения

1. `/start` с чистого аккаунта: приветствие, выбор языка, бонус начислен.
2. Вопрос в чат: ответ появляется постепенно, под ним подпись со списанием.
3. Голосовое: «Вы сказали: …» и ответ; списание за распознавание в истории.
4. `/image`: карточка с пропорциями → картинка с кнопками; «Изменить» работает.
5. `/video`: карточка с ценой → прогресс → ролик приходит сообщением;
   «Продлить» и «Поделиться» (ссылка открывается).
6. `/studio`: герой → сцена в ленту → «Примерить» → «Снять» → пуш о
   готовности → «Собрать» → мультфильм; кнопка Mini App открывает ту же ленту.
7. `/topup`: условия → счёт → оплата Stars → «Оплата прошла», тир paid,
   премиум-модель открылась; в админке платёж с провайдером Telegram Stars;
   «Вернуть Stars» снимает кредиты.
8. Профиль → «Связать с аккаунтом сайта» по коду с почты: баланс объединился.
9. Пополните на сайте — в бот приходит сообщение о зачислении.
10. Заблокируйте бота и разблокируйте: пуши останавливаются и возобновляются.
