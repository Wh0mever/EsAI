# Telegram-бот EsAI

## Что сделано и где оно живёт

| Слой | Где | Что делает |
|---|---|---|
| Бэкенд | `core/botapi/` | Обмен «данные Telegram → токен человека», настройки уведомлений, отправка сообщений из ядра |
| Бот | `bot/` | Отдельный сервис на aiogram: чат, модели, файлы, баланс, история, приглашения |
| Вход Mini App | `core/botapi/views.py::WebAppAuthView` | Проверка подписи `initData`, выдача токенов веб-версии внутри Telegram |

Бот — тонкий клиент нашего же API. Он не считает деньги, не ходит в базу и не
знает ключей моделей: списания, лимиты, антифрод и история остаются на сайте,
по тем же адресам, что использует веб-фронт. Поэтому деньги считаются в одном
месте, а не в двух, и бот нельзя «обмануть» в обход сайта.

## Аккаунт общий с сайтом

Вход через Telegram на сайте заводит `SocialAccount(provider="telegram",
uid=<id пользователя>)` и пользователя с почтой-заглушкой
`telegram_<id>@social.esai.local`. Бот ищет и создаёт ровно то же самое —
а id пользователя в Telegram один на все боты. Поэтому человек, который
пополнил баланс на сайте, видит эти кредиты в боте, и наоборот. Склеивать
аккаунты потом не придётся.

Товарный бот и бот входа на сайт — **разные боты с разными токенами**
(`TELEGRAM_PRODUCT_BOT_TOKEN` и `TELEGRAM_BOT_TOKEN`). На общий аккаунт это
не влияет по причине выше.

## Включение

```bash
cd /opt/esai && bash scripts/bot-up.sh
```

Скрипт спросит токен от @BotFather (ввод скрыт), проверит его у Telegram
**до** записи в `.env`, сам сгенерирует служебный секрет, поднимет сервис и
покажет самопроверку. Ваш Telegram id можно узнать у @userinfobot.

Бот стартует в режиме `staff` — отвечает только тем, чьи id перечислены в
`BOT_STAFF_IDS`. После обкатки:

```bash
bash scripts/bot-open.sh    # отвечает всем
```

Проверить окружение в любой момент:

```bash
docker compose exec bot python -m bot.selfcheck
docker compose logs -f bot
```

## Что уже работает

- `/start` — приветствие, выбор языка (ru/en/kg), восемь стартовых подсказок
  как на сайте; ссылки `?start=ref_КОД` и `?start=promo_КОД` разбираются.
- Чат с любой моделью: ответ показывается по мере появления, под ним —
  «повторить», «продолжить», источники и ход рассуждений, если модель их дала.
- `/model` — те же группы и пометки, что на сайте, с ценой и «🔒 Премиум».
- Файлы: PDF, Word, Excel, PowerPoint, TXT и фото; готовые действия
  (пересказать, выделить главное, проверить договор, перевести).
- `/balance`, `/history`, `/referral`, `/promo`, `/help`.
- Уведомления от сайта в бот: пополнение баланса, реферальные начисления,
  ежедневный бонус (одной рассылкой с разбегом, чтобы не упереться в лимит).

## Чего ещё нет

- **Оплата внутри бота.** По правилам Telegram цифровые товары в ботах и
  Mini App продаются только за Telegram Stars; ссылки на карту и крипту из
  бота давать нельзя — за это бота скрывают на iOS и Android. Сейчас кнопка
  пополнения ведёт на сайт, где у человека тот же аккаунт и баланс. Stars —
  следующий этап (нужны решения владельца: см. план, раздел 3.6).
- Голосовые: распознавания на бэкенде нет, бот честно говорит об этом.
- Мастера картинок и видео с параметрами, студия мультфильмов, Mini App —
  спроектированы в плане, не реализованы.

## Ограничения, которые важно помнить

- Опрос Telegram ведёт **ровно один процесс** (блокировка в Redis). Второй с
  тем же токеном Telegram просто не пустит.
- Сообщение — до 4096 символов, правка не чаще раза в секунду на чат. Длинные
  ответы режутся по абзацам, теги закрываются на границе кусков: иначе
  Telegram отвергает сообщение целиком.
- Скачать присланный файл бот может до 20 МБ (предел Telegram), наш API
  принимает до 15 МБ, фото отправляется до 10 МБ. Это три разных предела.
- `TELEGRAM_NOTIFY_ENABLED=0` полностью выключает исходящие сообщения.
- Пустой `BOT_SERVICE_SECRET` закрывает служебные эндпоинты — то есть до
  включения бот физически не может ничего сделать с аккаунтами.

## Тесты

```bash
# бэкенд (на стенде, не на проде)
cd core && TEST_DB=test_bot python manage.py test botapi --settings=core.settings_localtest

# бот
cd bot && python -m pytest tests -q
```

Ни один тест не ходит в сеть: Telegram и наш API подменяются заглушками.

## Что проверить после включения

1. `/start` с чистого аккаунта: приходит приветствие, начислен бонус.
2. Вопрос в чат: ответ появляется постепенно, под ним подпись со списанием.
3. Длинный ответ (попросите статью на 5000 знаков): приходит несколькими
   сообщениями, разметка не рассыпается.
4. `/model` → премиум-модель: показывается пейвол, а не ошибка.
5. Пришлите PDF: предлагаются действия, «пересказать» отвечает по документу.
6. Баланс в боте совпадает с балансом на сайте под тем же аккаунтом.
7. Пополните на сайте — в бот приходит сообщение о зачислении.
