# Telegram-бот EsAI

Бот — тонкий клиент нашего же API. Он не считает деньги и не ходит в базу:
списания, лимиты, антифрод и история живут на сайте, по тем же адресам, что
использует веб-фронт. Поэтому у человека один аккаунт и один баланс: вошёл
через Telegram на сайте или написал боту — это один и тот же пользователь.

## Запуск на своей машине

1. Заведите тестового бота у @BotFather и возьмите токен.
2. В `.env` проекта:

   ```
   TELEGRAM_PRODUCT_BOT_TOKEN=<токен тестового бота>
   TELEGRAM_PRODUCT_BOT_USERNAME=<имя бота без @>
   BOT_SERVICE_SECRET=<openssl rand -hex 32>
   BOT_ACCESS=staff
   BOT_STAFF_IDS=<ваш telegram id>
   ```

3. Поднимите бэкенд (`core`) и Redis, затем:

   ```
   BOT_API_BASE=http://127.0.0.1:8000 BOT_PUBLIC_HOST=127.0.0.1:8000 python -m bot
   ```

## Тесты

```
cd bot && python -m pytest tests -q
```

Тесты не ходят в сеть: Telegram и наш API подменяются заглушками.

## Что где

- `bot/config.py` — настройки из общего `.env`.
- `bot/services/api.py` — клиент API: подпись служебных запросов, поток ответа.
- `bot/services/stream.py` — показ ответа по мере появления.
- `bot/services/tg_format.py` — Markdown модели → разметка Telegram.
- `bot/services/state.py` — короткая память бота в Redis (токен, модель, чат).
- `bot/routers/` — экраны: старт, чат, выбор модели.
- `bot/middlewares/auth.py` — узнаём человека, ловим повторные апдейты.

## Ограничения, о которых стоит помнить

- Опрос Telegram ведёт ровно один процесс (блокировка в Redis). Второй с тем
  же токеном Telegram просто не пустит.
- Сообщение в Telegram — до 4096 символов, правка не чаще раза в секунду.
  Длинные ответы режутся по абзацам, теги закрываются на границе кусков.
- Скачать присланный файл бот может до 20 МБ (ограничение Telegram),
  отправить — до 50 МБ; фото — до 10 МБ.
- Продавать кредиты внутри бота можно только за Telegram Stars: по правилам
  Telegram цифровые товары в ботах и Mini App продаются только так. Пополнение
  картой и криптой остаётся на сайте, аккаунт и баланс общие.
